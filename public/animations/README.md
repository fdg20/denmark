# Animation Assets Directory

This directory is for storing animation assets used in the ProjectMotionGraphics component.

## Placeholder Files

Currently, the component uses programmatically generated SVG animations. You can replace these with:

- Lottie animation files (`.json`)
- Custom SVG animations
- Other animation formats as needed

## Usage

To use a custom animation file, update the `ProjectMotionGraphics.jsx` component to load and render your animation file instead of the programmatic SVG generation.

## File Naming Convention

- `project-motion-*.json` - Lottie animations
- `project-motion-*.svg` - SVG animations
- `project-motion-*.mp4` - Video animations (if needed)
